# Barber Bot - Telegram Bot for Barbershop Appointments

Telegram бот для записи клиентов в барбершоп с функционалом управления расписанием, автоматическими напоминаниями и уведомлениями.

## Функционал

### Для барбера
- 📅 **Планирование сеансов** - создание расписания с выбором разных длительностей для разных услуг
- ⏱️ **Динамическая длительность услуг** - отдельно задаёт время для стрижки и стрижки+бороды
- 📢 **Публикация расписания** - уведомление всех подписчиков о доступных местах
- 📊 **Управление записями** - просмотр и отмена записей с указанием причины
- 📍 **Уведомления о новых записях** - мгновенное сообщение когда клиент записывается
- 🔔 **Уведомления об освобождении мест** - сообщение когда место освобождается
- 👤 **Профиль** - просмотр и редактирование имени и номера телефона
- 💰 **Управление услугами и ценами** - установка цен на услуги (стрижка, стрижка бороды, комбо)
- 👥 **Список клиентов** - просмотр всех клиентов с информацией о них
- 🚫 **Чёрный список** - блокировка клиентов от получения уведомлений
- ✏️ **Ручная запись клиентов** - запись клиента с выбором услуги и времени

### Для клиента
- 📅 **Просмотр расписания** - доступные даты и временные слоты
- 🪒 **Выбор услуги** - выбор типа услуги перед бронированием (стрижка или стрижка+борода)
- ✂️ **Запись к барберу** - выбор даты, времени и подтверждение
- 📝 **Мои записи** - просмотр активных записей и истории
- ❌ **Отмена записи** - возможность отменить запись
- ⏰ **Автоматические напоминания** - настраиваемое время напоминания (7:00-21:00) в день приёма
- 👤 **Профиль** - просмотр и редактирование имени, номера телефона и времени напоминания
- 💰 **Просмотр прайс-листа** - просмотр цен на все услуги барбера
- 🗑️ **Удаление аккаунта** - возможность удалить профиль (только для клиентов)
- 🚀 **Кнопка Start** - удобный старт для новых пользователей при первом входе
- 🎁 **Реферальная программа** - пригласить друзей и получить бонусные баллы

## Технический стек

- **Python 3.10+**
- **aiogram 3.x** - Telegram Bot API фреймворк
- **MongoDB** - база данных

## Установка

### Требования
- Python 3.10+
- MongoDB (локально или в облаке)
- Telegram Bot Token (получить от @BotFather)

### Важно
Проект **не использует** .env файлы. Все параметры передаются через **переменные окружения**:
- Локально: `export TELEGRAM_BOT_TOKEN="..."`
- Docker: `environment` в docker-compose.yml или флаг `-e` при запуске

### Шаги установки

1. **Клонируйте репозиторий**
```bash
git clone <repo-url>
cd TelegramBot
```

2. **Создайте виртуальное окружение**
```bash
python -m venv venv
source venv/bin/activate  # на Windows: venv\Scripts\activate
```

3. **Установите зависимости**
```bash
pip install -r requirements.txt
```

4. **Установите переменные окружения**
```bash
export TELEGRAM_BOT_TOKEN="your_bot_token_here"
export MONGODB_URI="mongodb://localhost:27017"
export DATABASE_NAME="barber_bot"
export TIMEZONE="Europe/Moscow"
export LOG_LEVEL="INFO"
```

5. **Запустите бот**
```bash
python -m src.main
```

## Последние изменения (Текущая сессия)

### 🐛 Исправления ошибок

1. **Исправлена ошибка сохранения цены для услуг "борода" и "комбо"**
   - Проблема: парсинг `service_type` из callback_data неправильно разбирал многословные названия
   - Было: `callback.data.split("_")[-1]` → для "save_price_beard_trim" давало "trim"
   - Стало: `callback.data.replace("save_price_", "")` → корректно получает "beard_trim" и "haircut_and_beard"
   - Теперь все три услуги (стрижка, борода, комбо) сохраняют цену правильно

2. **Исправлена ошибка отображения пустого чёрного списка**
   - Кнопка "🚫 Чёрный список" больше не показывается, если там нет заблокированных клиентов
   - Раньше: показывалась кнопка "Чёрный список (0)", но при открытии писало "нет клиентов"
   - Теперь: кнопка видна только если есть заблокированные клиенты

### ✨ Новые функции

1. **Динамическая длительность услуг (две разные длительности)**
   
   **Для барбера при создании расписания:**
   - Вместо выбора одной длительности теперь выбирает ДВЕ:
     - Длительность для **стрижки** (например, 60 мин)
     - Длительность для **стрижки + бороды** (например, 90 мин)
   - Слоты больше не генерируются при создании, а генерируются динамически
   
   **Для клиента при букинге:**
   - Сначала выбирает **тип услуги** (Стрижка или Стрижка + Борода)
   - Потом выбирает **дату**
   - Затем видит **доступные слоты** для выбранной услуги с правильной длительностью
   - Пример: если клиент выбрал "Стрижка + Борода" (90 мин), слоты будут рассчитаны на 90 минут
   
   **Для барбера при ручной записи клиента:**
   - Выбирает клиента → дату → время
   - Теперь также выбирает **тип услуги** перед подтверждением
   - Запись создается с корректной длительностью для выбранной услуги

2. **Обновлены модели данных**
   - `Schedule`: теперь хранит `haircut_duration_minutes` и `haircut_and_beard_duration_minutes` вместо `session_duration_minutes`
   - `Appointment`: добавлено поле `service_type` для отслеживания какую услугу выбрал клиент
   - Слоты больше не сохраняются в БД, генерируются на лету для каждой услуги

3. **Улучшена система бронирования**
   - Динамическая генерация слотов в ScheduleService методом `get_available_slots_for_service()`
   - Поддержка как старой логики (ID-based slots), так и новой (object-based slots) в `AppointmentService.book_appointment()`
   - В уведомлениях теперь отображается тип услуги: "Стрижка" или "Стрижка + Борода"

### 🔧 Технические улучшения

- Переписана логика создания расписания: вместо предварительной генерации слотов используется динамическая генерация
- Добавлены новые состояния FSM: `BookingStates` для клиента, `BarberBookingStates` для барбера
- Улучшена архитектура ScheduleService с методами для динамической работы со слотами
- Добавлены проверки при отображении кнопок (кнопка чёрного списка показывается только если там есть клиенты)

## Архитектура

Проект использует чистую архитектуру с разделением ответственности:

- **Handlers** - обработка Telegram команд (делегирует на бизнес-логику)
- **Services** - бизнес-логика (без зависимости от Telegram)
- **Repositories** - доступ к БД (абстракция от MongoDB)
- **Models** - валидация данных (Pydantic)

## Миграции данных

python scripts/migrate_reminder_time.py
